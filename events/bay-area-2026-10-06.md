## Pre-Work

### 1. Get a Snowflake trial account

Use the event-specific link below. It activates the AI features this workshop
needs, and only for accounts created inside the activation window.

> **Trial link:** https://signup.snowflake.com/?t=47ba5904df6af5304e79840925984272cf4c20b0c4bb3df6ce47d945041dae1d&cloud=aws&region=us-east-2
> **Activation window:** starts October 4, 2026 (UTC) — accounts created
> outside this window are plain trials without AI features.

At signup: choose **AWS** and the suggested region, and select **AI Data Cloud
For Enterprise** from the toggle at the top of the page. Do not change the
region — changing it removes AI features.

> **Already have a trial from a previous session?** Create a fresh one with the
> link above. Older trials may not have the AI features this workshop needs, and
> free trials expire after 30 days.

@snowflake.com emails are exempt from the activation window (useful for
presenters testing before the session).

### 2. Install the CoCo CLI

**Option A — CLI (recommended for this session):**

```bash
# macOS / Linux / WSL
curl -LsS https://ai.snowflake.com/static/cc-scripts/install.sh | sh

# Windows (PowerShell)
irm https://ai.snowflake.com/static/cc-scripts/install.ps1 | iex
```

Confirm: `cortex --version`

**Option B — CoCo Desktop:** https://www.snowflake.com/en/product/snowflake-coco/downloads/

### 3. Bring a laptop

Terminal, a code editor (VS Code, Cursor, or similar), and admin rights to
install a CLI tool. Wi-Fi is provided.
